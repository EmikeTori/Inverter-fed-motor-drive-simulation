This project develops a MATLAB/Simulink simulation of a traction-style electric drive: a DC source feeding a three-phase inverter with PWM switching, which drives a motor whose speed is regulated by a PI controller. The aim is to understand how inverter switching, motor dynamics and feedback control interact, and to test how well the drive tracks a speed reference and rejects a sudden load-torque change. Performance will be measured through rise time, overshoot, settling time, steady-state error and phase currents. The project is a self-directed, simulation-only study with no hardware, intended to build practical foundations in electric vehicle propulsion and control. The control method used and the model’s limitations will be stated explicitly in the final report.
